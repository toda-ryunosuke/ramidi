# Ramidi (Recomposer Assembler MIDI)

**Ramidi (らみでぃ)** は、テキストデータ（`.ramidi`）から、MIDIファイル生成、FluidSynthによるオーディオレンダリング、
FFmpegによるマスタリング、そしてSNS投稿向けMP4動画の生成までを行う音楽制作パイプラインツールです。

名前からも分かるとおり、レコンポーザのステップ入力方式にインスパイアされた、
MIDIニーモニックベースの独自DSL（ドメイン固有言語）を用いて楽曲を記述します。

DSLは主にAIが記述・編集するために設計されています。つまりAI作曲を前提としています。  
付属のドキュメント `SYNTAX.md` をAIに読ませて使用してください。

## 前提条件

### 必要な外部ツール

Ramidi を実行するためには、お使いのシステムに以下のソフトウェアがインストールされ、パスが通っている必要があります。

1. **FluidSynth**: MIDIファイルをオーディオ（RAW WAV）にレンダリングするために使用します。
2. **FFmpeg**: レンダリングされたオーディオファイルのマスタリング処理（音圧・音質調整）および MP4
   動画生成（波形アニメーション合成）に使用します。

#### macOS の場合 (Homebrew)

```bash
brew install fluidsynth ffmpeg
```

#### Windows の場合 (winget)

```bash
winget install FluidSynth.FluidSynth
winget install Gyan.FFmpeg
```

### SoundFontの準備

Ramidi でオーディオをレンダリングするには、 **SoundFont (.sf2 または .sf3)** ファイルが必要です。

代表的な SoundFont:

- `GeneralUser GS` (`GeneralUser.sf2`)
- `FluidR3_GM` (`FluidR3_GM.sf2`)

プロジェクトルートの `soundfonts` ディレクトリに SoundFont ファイルを配置してください。  
配置場所やエイリアスを変更したい場合は、設定ファイル `application.properties` で指定できます。

## クイックスタート

### 基本的な実行方法

最も基本的な使い方は、`.ramidi` ファイルを作成し、以下のコマンドを実行するだけです。

```bash
ramidi <入力ファイル.ramidi>
```

実行すると、以下のファイルが生成されます。

1. `<ファイル名>.mid`
2. `<ファイル名>.raw.wav`: SoundFontによるレンダリング直後のWAVファイル
3. `<ファイル名>.wav`: マスタリング処理を施した最終的なWAVファイル
4. `<ファイル名>.mp4`

処理完了後、最終成果物がOS標準のプレイヤーで自動再生されます。

## コマンドライン操作

### コマンドライン引数（オプション）

Ramidi は以下のコマンドライン引数に対応しています。

| オプション        | 引数                                          | 説明                                                                                                                                                                                                                                                                                                       |
|:------------------|:----------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--stage=<stage>` | `midi`, `raw`, `wav` (または `master`), `mp4` | 処理を終了するステージを指定します（デフォルト: `mp4`）。<br>- `midi`: SMF形式のMIDIファイル生成までで終了します。<br>- `raw`: FluidSynthによるRAW WAVレンダリングまでで終了します。<br>- `wav` (または `master`): マスタリング処理（WAV）までで終了します。<br>- `mp4`: MP4動画生成まですべて実行します。 |
| `--cover=<path>`  | 画像ファイルパス                              | MP4生成時に背景として使用するジャケット画像ファイルのパスを指定します。<br>未指定時のデフォルト動作:<br>入力 `.ramidi` と同階層にある `cover.jpg` を優先して探索し、なければ `cover.png` を使用します。画像がない場合は波形アニメーション（ビジュアライザ）動画が自動生成されます。                        |
| `--no-play`       | なし                                          | 処理完了後のOS標準プレイヤーによる自動再生を無効化します。CI/CD環境やバッチ処理などで便利です。                                                                                                                                                                                                            |

#### コマンドライン引数の実行例

```bash
# MIDIファイルのみを高速に出力（オーディオレンダリングをスキップ）
ramidi song.ramidi --stage=midi

# マスタリング済みWAVまで出力し、再生は行わない
ramidi song.ramidi --stage=wav --no-play

# 独自のジャケット画像を指定してMP4動画を生成
ramidi song.ramidi --cover=/path/to/artwork.png
```

## MP4動画生成機能

### MP4動画の仕様

- **解像度**: 1280 x 720 (HD, 16:9)
- **フレームレート**: 30 fps
- **映像コーデック**: H.264 (`libx264`), ピクセルフォーマット `yuv420p`
- **音声コーデック**: AAC (`320kbps`, 44.1kHz)
- **波形表示**: LR独立の2チャンネル（マルチチャンネル）波形アニメーション（`Cyan` / `Magenta`）

### カバー画像の自動判定

1. **カバー画像がある場合**:
    - 入力ファイルと同階層の `cover.jpg` または `cover.png`（または `--cover` で指定された画像）を
      1280x720 に自動クロップ・リサイズして背景に配置します。
    - 背景画像の下部（下端から40px上）に、高さ240pxのLR分割波形アニメーションが美しく合成されます。
2. **カバー画像がない場合**:
    - 黒背景の中央にLR分割波形アニメーションが配置された動画が生成されます。カバー画像が用意されていない状態でも問題なく動画出力が可能です。
