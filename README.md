# Ramidi (Recomposer Assembler MIDI)

---

**RAMIDI (らみでぃ)** は、テキストデータ（`.ramidi`）から、MIDIファイル生成、FluidSynthによるオーディオレンダリング、
そしてFFmpegによるマスタリングまでを行う、音楽制作パイプラインを提供するコマンドラインツールです。

名前からも分かるとおり、レコンポーザのステップ入力方式にインスパイアされた、
MIDIニーモニックベースの独自DSL（ドメイン固有言語）を用いて楽曲を記述します。

DSLは主にAIが作曲するために設計されています。

---

## 🛠️ 前提条件（必要なソフトウェア）

Ramidi を実行するためには、お使いのシステムに以下のソフトウェアがインストールされ、パスが通っている必要があります。

1. **FluidSynth**: MIDIファイルをオーディオ（WAV）にレンダリングするために使用します。
2. **FFmpeg**: レンダリングされたオーディオファイルのマスタリング処理（音圧調整、エフェクト適用など）に使用します。

## 🎹 SoundFontの準備

Ramidi で音を鳴らすには、**SoundFont (.sf2 または .sf3)** ファイルが必要です。

代表的な SoundFont:

- GeneralUser.sf2
- FluidR3_GM.sf2

設定ファイル `application.properties` にパスを指定して使用します。

---

## 🚀 Getting Started

最も基本的な使い方は、`.ramidi` ファイルを作成し、以下のコマンドを実行するだけです。

```bash
ramidi [ファイル名.ramidi]
```

実行すると、以下の3つのファイルが生成されます。

1. `[ファイル名].mid`: SMF (Standard MIDI File) 形式のMIDIファイル
2. `[ファイル名].raw.wav`: SoundFontによるレンダリング直後のWAVファイル
3. `[ファイル名].wav`: マスタリング処理を施した最終的なWAVファイル

そしてマスタリング済みの最終WAVファイルがOSの標準プレイヤーで再生されます。

# Ramidi 構文仕様

★はレコンポーザにはない Ramidi オリジナル機能です。

## 基本概念

- **ファイル形式**: UTF-8のテキストファイル。
- **コメント**: `#` から行末までがコメントになります。
- **コマンド形式**: `COMMAND, param1, param2, ...` のようにカンマ区切りのテキストです。
  **コマンド名**と **コード名**
  は大文字・小文字を区別しませんが、それ以外の引数（マクロID、ファイル名など）は区別される可能性があるため、正確に記述することを推奨します。
- **数値の16進数表記**: ★ 数値パラメータは、`0x` または `0X`
  を先頭に付与することで16進数表記で記述することも可能です（例: `0x7F`）。
- **ダブルクォーテーションの扱い**: コマンド名や各パラメータはダブルクォーテーション（`"`
  ）で囲むことも可能ですが、解析時に自動的に除去されるため、囲むことによる特別な意味はありません。
- **Tick**: 時間の最小単位。分解能は四分音符あたり **480 Ticks** です。
- **トラック**: 演奏パートの単位。0から127までのトラック番号で管理されます。各トラックは独立したTickカウンターを持ちます。
- **パラメータの継承**: ★
  コマンドの各パラメータは省略（カンマのみを記述）可能です。省略されたパラメータ（コマンド自体も含む）は、直前の行の同じ位置の値を自動的に引き継ぎます。これにより、差分のみを記述する効率的な入力が可能です。

**パラメータ継承の例:**

```
# 通常の記述
NOTE, 1, 1, 240, 60, 100, 200
NOTE, 1, 1, 240, 62, 100, 200
NOTE, 1, 1, 240, 64, 100, 200

# 上記は以下のように省略可能
NOTE, 1, 1, 240, 60, 100, 200
, , , , 62, ,       # NOTE, 1, 1, 240, 62, 100, 200 と同じ
, , , , 64, ,       # NOTE, 1, 1, 240, 64, 100, 200 と同じ
```

## グローバル設定コマンド

生成プロセス全体に影響を与える設定を行います。１回のみ有効です。

| コマンド             | パラメータ                   | 説明                                                                                          |
|:-----------------|:------------------------|:--------------------------------------------------------------------------------------------|
| `USE_SOUNDFONT`  | `aliasOrFilename` (文字列) | 使用するSoundFontを指定します。`application.properties`で定義されたエイリアス、または直接ファイル名を指定できます。                  |
| `MASTERING_TYPE` | `type` (文字列)            | 出力WAVに適用するマスタリングプリセットを指定します。デフォルトは `EDM` です。<br>種類: `EDM`, `POP`, `CLASSIC`, `LOFI`, `NONE` |

## 高レベルコマンド

### タイムライン制御

| コマンド        | パラメータ                      | 説明                                                           |
|:------------|:---------------------------|:-------------------------------------------------------------|
| `SET_TICK`  | `trk` (整数), `absTick` (整数) | 指定トラック(`trk`)のTickカウンターを、指定した絶対Tick位置(`absTick`)に強制的に移動させます。 |
| `KEY_SHIFT` | `trk` (整数), `shift` (整数)   | ★ 指定トラックのすべてのノートを指定した半音数(`shift`)だけ移調します。負の値も指定可能です。         |

### ノート・演奏コマンド

これらのコマンドは **ST (Step Time)** で発音タイミングを指定します。STは、 **同じトラック**
の直前のイベントからの相対Tick差です。

- `ST > 0`: 指定Tick数だけ時間を進めて発音します。
- `ST = 0`: 直前のイベントと同時に発音します（和音などで使用）。
- `ST < 0`: ★ 指定Tick数だけ **時間を巻き戻して**発音します。これにより、突っ込みや先走りのような表現が可能です。この機能は
  Singer Song Witer という製品の考え方を取り入れたものです。

| コマンド       | パラメータ                                              | 説明                                                                                           |
|:-----------|:---------------------------------------------------|:---------------------------------------------------------------------------------------------|
| `NOTE`     | `trk`, `ch`, `ST`, `note`, `vel`, `gate`           | 単音を発音します。<br>- `note`: MIDIノート番号 (0-127)<br>- `vel`: ベロシティ (1-127)<br>- `gate`: 発音時間 (Ticks) |
| `CHORD`    | `trk`, `ch`, `ST`, `chord`, `vel`, `gate`          | ★ 和音を一斉に発音します。<br>- `chord`: コード名 (例: `C4maj7`)                                              |
| `ARPEGGIO` | `trk`, `ch`, `ST`, `chord`, `vel`, `gate`, `delay` | ★ 和音を分散させてアルペジオ演奏します。<br>- `delay`: 各構成音間の遅延 (Ticks)                                         |

#### コードネームの書式 (`chord`)

`[ルート音][オクターブ][タイプ]` の形式で指定します (例: `F#3min7`, `C4maj`, `Db7`)。

- **ルート音**: `C`, `C#`, `Db`, `D`, ... `B`
- **オクターブ**: `0` から `8` までの数字。省略した場合は `4` になります。
- **タイプ**:
    - `maj` または省略: メジャーコード (構成音: 0, 4, 7)
    - `min`, `m`: マイナーコード (0, 3, 7)
    - `maj7`: メジャーセブンス (0, 4, 7, 11)
    - `min7`, `m7`: マイナーセブンス (0, 3, 7, 10)
    - `7`: ドミナントセブンス (0, 4, 7, 10)
    - `dim`: ディミニッシュ (0, 3, 6)

### 演奏制御コマンド

| コマンド         | パラメータ                                 | 説明                            |
|:-------------|:--------------------------------------|:------------------------------|
| `PROGRAM`    | `trk`, `ch`, `ST`, `progNum`          | プログラムチェンジ（音色変更）。              |
| `CC`         | `trk`, `ch`, `ST`, `ccNum`, `val`     | コントロールチェンジ。                   |
| `BEND`       | `trk`, `ch`, `ST`, `val`              | ピッチベンド。値の範囲は `-8192`〜`+8191`。 |
| `POLY_PRESS` | `trk`, `ch`, `ST`, `note`, `pressure` | ポリフォニック・アフタータッチ。              |
| `CHAN_PRESS` | `trk`, `ch`, `ST`, `pressure`         | チャンネル・アフタータッチ。                |

### 自動スウィープコマンド

指定した時間 (`duration`)をかけて、パラメータ値を線形に変化させます。

**⚠️ 重要: スウィープ終了後のTick位置について**
各スウィープコマンドの実行後、そのトラックのTickは**自動的にスウィープ終了位置 (`ST` + `duration`) まで進みます。**
そのため、「音を鳴らしながら裏でスウィープさせたい」場合は、スウィープコマンドの直後に続く `NOTE` などの `ST` を `0` またはマイナスに設定して、発音タイミングを調整する必要があります。
逆に、スウィープが終わってから次の音を鳴らしたい場合は、そのまま `ST` を積んでいくだけで記述できます。

| コマンド          | パラメータ                                                          | 説明                                                                                                        |
|:--------------|:---------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| `SWEEP_CC`    | `trk`, `ch`, `ST`, `duration`, `ccNum`, `start`, `end`, `step` | ★ CC値を `start` から `end` まで滑らかに変化させます。<br>- `step`: 値を更新する間隔 (Ticks)。                                      |
| `SWEEP_BEND`  | `trk`, `ch`, `ST`, `duration`, `start`, `end`, `step`          | ★ ピッチベンド値を `start` から `end` まで変化させます。<br>- 範囲: `-8192` (最低) 〜 `+8191` (最高)<br>- `step`: 値を更新する間隔 (Ticks)。 |
| `SWEEP_TEMPO` | `trk`, `ST`, `duration`, `startBpm`, `endBpm`, `step`          | ★ テンポを滑らかに変化させます（アッチェレランド/リタルダンド）。<br>- `step`: 値を更新する間隔 (Ticks)。                                         |

### マクロ機能

| コマンド         | パラメータ                                                | 説明                                                                                                                                                                                                      |
|:-------------|:-----------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DEF_MACRO`  | `id` (文字列)                                           | ★ マクロ定義を開始します。`END_MACRO` までを一つの塊として記憶します。別名: `DEF_PATTERN`。<br>定義内には `$1`, `$2` のようにプレースホルダーを使用できます。さらに、16進数フォーマットで展開される `$x1` (小文字), `$X1` (大文字) も使用可能です。                                             |
| `END_MACRO`  | (なし)                                                 | ★ マクロ定義を終了します。                                                                                                                                                                                          |
| `CALL_MACRO` | `id`, `count`, `transpose`, `velOffset`, `[args...]` | ★ マクロを呼び出します。別名: `CALL_PATTERN`。<br>- `count`: 繰り返し回数<br>- `transpose`: マクロ内の全ノートを移調 (半音単位)<br>- `velOffset`: マクロ内の全ノートのベロシティを増減 <br>- `args...`: ★ マクロ内の `$1`, `$2`, ... に代入する任意の文字列（変数引数）。何個でも指定可能です。 |

**マクロ引数の使用例:**

```
DEF_MACRO, MY_MELODY
  NOTE, 1, 1, 0, $1, 100, 240   # $1 が第1引数に置き換わります
  NOTE, 1, 1, 240, $2, 100, 240  # $2 が第2引数に置き換わります
  SYSEX, 1, 0, "F0 43 10 4C 02 01 00 $X3 F7" # $X3が第3引数の16進数大文字に置き換わります
END_MACRO

# 呼び出し時にノート番号やSysExパラメータを引数として渡す
CALL_MACRO, MY_MELODY, 1, 0, 0, 60, 64, 127
```

### ループと分岐

ループはネスト（入れ子に）することができます。

| コマンド         | パラメータ        | 説明                                                 |
|:-------------|:-------------|:---------------------------------------------------|
| `LOOP_START` | `count` (整数) | ★ ループブロックを開始します。`END_LOOP` までを `count` 回繰り返します。    |
| `LOOP_END`   | (なし)         | ★ ループブロックを終了します。                                   |
| `LOOP_LAST`  | (なし)         | ★ この行以降のコマンドは、ループの **最終回のみ** 実行されます。フィルインなどに使用します。 |
| `LOOP_NOT_LAST` | (なし)         | ★ この行以降のコマンドは、ループの **最終回以外** で実行されます。              |

**ループ分岐の例:**

```
LOOP_START, 4       # 4回ループ
  # --- 1〜3回目と4回目共通のパターン ---
  NOTE, 9, 9, 0, 36, 120, 100

  LOOP_NOT_LAST        # --- 最終回以外 (1〜3回目) ---
  NOTE, 9, 9, 480, 38, 100, 100 # 通常のスネア

  LOOP_LAST         # --- 最終回 (4回目) のみ ---
  NOTE, 9, 9, 480, 49, 127, 240 # フィルインのクラッシュシンバル

LOOP_END
```

## 低レベルコマンド

これらのコマンドは **絶対Tick** でイベントの発生位置を指定します。通常は高レベルコマンドから自動生成されます。

### チャンネルメッセージ

### メタイベント

| コマンド        | パラメータ                           | 説明                                                                              |
|:------------|:--------------------------------|:--------------------------------------------------------------------------------|
| `TEMPO`     | `trk`, `tick`, `bpm`            | テンポ変更。                                                                          |
| `TIMESIG`   | `trk`, `tick`, `num`, `denom`   | 拍子記号。`denom` は4なら4分音符、8なら8分音符。                                                  |
| `KEYSIG`    | `trk`, `tick`, `sf`, `mi`       | 調号。`sf`: シャープ/フラットの数 (-7〜+7), `mi`: メジャー/マイナー (0=Maj, 1=Min)。                   |
| `META_TEXT` | `trk`, `tick`, `type`, `"text"` | テキストイベント。<br>- `type`: 1(Text), 2(Copyright), 3(TrackName), 5(Lyric), 6(Marker) |
