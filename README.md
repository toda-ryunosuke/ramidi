# Ramidi (Recomposer Assembler MIDI)

**RAMIDI (らみでぃ)** は、テキストデータ（`.ramidi`）から、MIDIファイル生成、FluidSynthによるオーディオレンダリング、
FFmpegによるマスタリング、そしてSNS投稿向けMP4動画の生成までを行う音楽制作パイプラインツールです。

名前からも分かるとおり、レコンポーザのステップ入力方式にインスパイアされた、
MIDIニーモニックベースの独自DSL（ドメイン固有言語）を用いて楽曲を記述します。

DSLは主にAIが記述・編集するために設計されています。つまりAI作曲を前提としています。  
このドキュメントをAIに読ませて使用してください。

## 前提条件

### 必要な外部ツール

Ramidi を実行するためには、お使いのシステムに以下のソフトウェアがインストールされ、パスが通っている必要があります。

1. **FluidSynth**: MIDIファイルをオーディオ（RAW WAV）にレンダリングするために使用します。
2. **FFmpeg**: レンダリングされたオーディオファイルのマスタリング処理（音圧・音質調整）および MP4
   動画生成（波形アニメーション合成）に使用します。

#### macOS の場合 (Homebrew)

```bash
brew install fluidsynth ffmpeg
```

#### Windows の場合 (winget)

```bash
winget install FluidSynth.FluidSynth
winget install Gyan.FFmpeg
```

### SoundFontの準備

Ramidi でオーディオをレンダリングするには、**SoundFont (.sf2 または .sf3)** ファイルが必要です。

代表的な SoundFont:

- `GeneralUser GS` (`GeneralUser.sf2`)
- `FluidR3_GM` (`FluidR3_GM.sf2`)

プロジェクトルートの `soundfonts` ディレクトリに SoundFont ファイルを配置してください。  
配置場所やエイリアスを変更したい場合は、設定ファイル `application.properties` で指定できます。

## クイックスタート

### 基本的な実行方法

最も基本的な使い方は、`.ramidi` ファイルを作成し、以下のコマンドを実行するだけです。

```bash
ramidi <入力ファイル.ramidi>
```

実行すると、以下の3つのファイルが生成されます。

1. `<ファイル名>.mid`
2. `<ファイル名>.raw.wav`: SoundFontによるレンダリング直後のWAVファイル
3. `<ファイル名>.wav`: マスタリング処理を施した最終的なWAVファイル
4. `<ファイル名>.mp4`

処理完了後、最終成果物がOS標準のプレイヤーで自動再生されます。

そしてマスタリング済みの最終WAVファイルがOSの標準プレイヤーで再生されます。

## Ramidi構文仕様

★はレコンポーザにはない Ramidi オリジナル機能です。

### 基本概念

- **ファイル形式**: UTF-8のテキストファイル。
- **コメント**: `#` から行末までがコメントになります。
- **コマンド形式**: `COMMAND, param1, param2, ...` のようにカンマ区切りのテキストです。
  **コマンド名**は大文字・小文字を区別しませんが、それ以外の引数（param1, param2,
  ...）は区別される可能性があるため、正確に記述することを推奨します。また、囲み文字（`"`）は解析時に自動除去されます。
- **数値の16進数表記**: ★ 数値パラメータは、`0x` または `0X`
  を先頭に付与することで16進数表記で記述可能です（例: `0x7F`）。
- **Tick**: 時間の最小単位。分解能は四分音符あたり **480 Ticks** です。
- **トラック**: 演奏パートの単位。`0` から `127` までのトラック番号で管理されます。各トラックは独立したTickカウンターを持ちます。
- **パラメータの継承（ショートハンド記法）**: ★
  コマンドの各パラメータは省略（カンマのみを記述）可能です。省略されたパラメータ（コマンド名自体も含む）は、直前の行の同じ位置の値を自動的に引き継ぎます。これにより、差分のみを記述する効率的な入力が可能です。

**パラメータ継承の例:**

```
# 通常の記述
NOTE, 1, 1, 240, 60, 100, 200
NOTE, 1, 1, 240, 62, 100, 200
NOTE, 1, 1, 240, 64, 100, 200

# 上記は以下のように省略可能
NOTE, 1, 1, 240, 60, 100, 200
, , , , 62, ,       # NOTE, 1, 1, 240, 62, 100, 200 と同じ
, , , , 64, ,       # NOTE, 1, 1, 240, 64, 100, 200 と同じ
```

### グローバル設定コマンド

生成プロセス全体に影響を与える設定を行います。指定は１回のみ有効です。

| コマンド             | パラメータ                   | 説明                                                                                                |
|:-----------------|:------------------------|:--------------------------------------------------------------------------------------------------|
| `USE_SOUNDFONT`  | `aliasOrFilename` (文字列) | 使用するSoundFontを指定します（デフォルト: `GeneralUser`）。`application.properties` で定義されたエイリアス、または直接ファイル名を指定できます。 |
| `MASTERING_TYPE` | `type` (文字列)            | 出力WAVに適用するマスタリングプリセットを指定します（デフォルト: `EDM`）。<br>指定可能な値: `EDM`, `POP`, `CLASSIC`, `LOFI`, `NONE`     |

#### マスタリングプリセット一覧

- `EDM`: クラブミュージック向け（音圧高め・コンプレッサー強め）
- `POP`: ポップス向け（標準的・マイルドなコンプレッサー）
- `CLASSIC`: クラシック・ピアノ向け（コンプレッサーなし、ダイナミクスを重視したラウドネス正規化）
- `LOFI`: レトロゲーム・8bit風（11025Hz/8bitダウンサンプリング処理）
- `NONE`: マスタリングをスキップ（FluidSynthの出力WAVそのまま）

### メタデータコマンド

| コマンド         | パラメータ                       | 説明                        |
|:-------------|:----------------------------|:--------------------------|
| `TITLE`      | `"曲名"` (文字列)                | 曲名を設定します。                 |
| `COPYRIGHT`  | `"著作権情報"` (文字列)             | 著作権情報を設定します。              |
| `TRACK_NAME` | `trk` (整数), `"トラック名"` (文字列) | 指定したトラック(`trk`)の名前を設定します。 |

### ファイル分割 (INCLUDE)

| コマンド      | パラメータ            | 説明                                                                 |
|:----------|:-----------------|:-------------------------------------------------------------------|
| `INCLUDE` | `filePath` (文字列) | ★ 指定したファイルの内容をその場に展開します。ファイルパスは記述元ファイルからの相対パスで指定します。循環参照はエラーとなります。 |

### タイムライン制御

| コマンド        | パラメータ                      | 説明                                                         |
|:------------|:---------------------------|:-----------------------------------------------------------|
| `SET_TICK`  | `trk` (整数), `absTick` (整数) | 指定トラック(`trk`)のTickカウンターを、指定した絶対Tick位置(`absTick`)に強制移動させます。 |
| `KEY_SHIFT` | `trk` (整数), `shift` (整数)   | ★ 指定トラックの以降のすべてのノートを指定した半音数(`shift`)だけ移調します。負の値も指定可能です。    |

### ノート・演奏コマンド

これらのコマンドは **ST (Step Time)** で発音タイミングを指定します。STは **同じトラック**
の直前のイベントからの相対Tick差です。

- `ST > 0`: 指定Tick数だけ時間を進めて発音します。
- `ST = 0`: 直前のイベントと同時に発音します（和音などで使用）。
- `ST < 0`: ★ 指定Tick数だけ **時間を巻き戻して**発音します。これにより、突っ込みや先走りのような表現が可能です。この機能は
  Singer Song Witer という製品の考え方を取り入れたものです。

| コマンド       | パラメータ                                              | 説明                                                                                                                                                                          |
|:-----------|:---------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `NOTE`     | `trk`, `ch`, `ST`, `note`, `vel`, `gate`           | 単音を発音します。<br>- `trk`: トラック番号 (0〜127)<br>- `ch`: MIDIチャンネル (0〜15)<br>- `ST`: ステップタイム (Ticks)<br>- `note`: ノート番号 (0〜127)<br>- `vel`: ベロシティ (1〜127)<br>- `gate`: 発音の長さ (Ticks) |
| `CHORD`    | `trk`, `ch`, `ST`, `chord`, `vel`, `gate`          | ★ 和音。コード構成音を一斉に発音します。<br>- `chord`: コード名 (例: `C4maj7`, `F#3min`)                                                                                                            |
| `ARPEGGIO` | `trk`, `ch`, `ST`, `chord`, `vel`, `gate`, `delay` | ★ アルペジオ。コード構成音を指定遅延で順次発音します。<br>- `delay`: 音と音の間の遅延時間 (Ticks)                                                                                                               |

#### コードネームの書式 (`chord`)

`[ルート音][オクターブ][タイプ]` の形式で指定します（例: `C4maj`, `F#3min7`, `Db7`）。

- **ルート音**: `C`, `C#`, `DB`, `D`, `D#`, `EB`, `E`, `F`, `F#`, `GB`, `G`, `G#`, `AB`, `A`, `A#`,
  `BB`, `B`
- **オクターブ**: `0` 〜 `8` の数字（省略時は `4`）
- **タイプ**:
    - `maj`, 空文字: メジャー (0, 4, 7)
    - `min`, `m`: マイナー (0, 3, 7)
    - `maj7`: メジャーセブンス (0, 4, 7, 11)
    - `min7`, `m7`: マイナーセブンス (0, 3, 7, 10)
    - `7`: ドミナントセブンス (0, 4, 7, 10)
    - `dim`: ディミニッシュ (0, 3, 6)

### 演奏制御コマンド（MIDIコントロール）

| コマンド         | パラメータ                                 | 説明                                      |
|:-------------|:--------------------------------------|:----------------------------------------|
| `PROGRAM`    | `trk`, `ch`, `ST`, `progNum`          | プログラムチェンジ（音色変更）。`progNum`: 0〜127        |
| `CC`         | `trk`, `ch`, `ST`, `ccNum`, `val`     | コントロールチェンジ。`ccNum`: 0〜127, `val`: 0〜127 |
| `BEND`       | `trk`, `ch`, `ST`, `val`              | ピッチベンド。値の範囲: `-8192` 〜 `+8191`（中央: 0）   |
| `POLY_PRESS` | `trk`, `ch`, `ST`, `note`, `pressure` | ポリフォニック・キープレッシャー（アフタータッチ）。              |
| `CHAN_PRESS` | `trk`, `ch`, `ST`, `pressure`         | チャンネル・プレッシャー（アフタータッチ）。                  |

### 自動スウィープコマンド

指定時間 (`duration`) をかけて、値を線形補間（リニアスウィープ）します。  
**※注意**: スウィープ実行後、そのトラックのTickは自動的に `ST + duration`
だけ進みます。そのため、「音を鳴らしながら裏でスウィープさせたい」場合は、スウィープコマンドの直後に続く
NOTE などの ST を 0 またはマイナスに設定して、発音タイミングを調整する必要があります。
逆に、スウィープが終わってから次の音を鳴らしたい場合は、そのまま ST を積んでいくだけで記述できます。

| コマンド          | パラメータ                                                          | 説明                                                                                                        |
|:--------------|:---------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| `SWEEP_CC`    | `trk`, `ch`, `ST`, `duration`, `ccNum`, `start`, `end`, `step` | ★ CC値を `start` から `end` まで滑らかに変化させます。<br>- `step`: 値を更新する間隔 (Ticks)。                                      |
| `SWEEP_BEND`  | `trk`, `ch`, `ST`, `duration`, `start`, `end`, `step`          | ★ ピッチベンド値を `start` から `end` まで変化させます。<br>- 範囲: `-8192` (最低) 〜 `+8191` (最高)<br>- `step`: 値を更新する間隔 (Ticks)。 |
| `SWEEP_TEMPO` | `trk`, `ST`, `duration`, `startBpm`, `endBpm`, `step`          | ★ テンポを滑らかに変化させます（アッチェレランド/リタルダンド）。<br>- `step`: 値を更新する間隔 (Ticks)。                                         |

### マクロ機能

パターンを定義し、移調・ベロシティオフセット・引数を指定して再利用できます。

| コマンド         | パラメータ                                                | 説明                                                                                                                                                         |
|:-------------|:-----------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DEF_MACRO`  | `id` (文字列)                                           | ★ マクロ定義を開始します（別名: `DEF_PATTERN`）。<br>定義内では `$1`, `$2` の置換引数や、16進数2桁展開の `$x1`(小文字), `$X1`(大文字) が利用可能です。                                                     |
| `END_MACRO`  | (なし)                                                 | ★ マクロ定義を終了します（別名: `END_PATTERN`）。                                                                                                                          |
| `CALL_MACRO` | `id`, `count`, `transpose`, `velOffset`, `[args...]` | ★ マクロを呼び出します（別名: `CALL_PATTERN`）。<br>- `count`: 繰り返し回数<br>- `transpose`: ノートの半音移調量<br>- `velOffset`: ノートのベロシティ増減量<br>- `args...`: `$1`, `$2`, ... に代入する引数列 |

**マクロ引数の使用例:**

```
DEF_MACRO, MY_MELODY
  NOTE, 1, 1, 0, $1, 100, 240   # $1 が第1引数に置き換わります
  NOTE, 1, 1, 240, $2, 100, 240  # $2 が第2引数に置き換わります
  SYSEX, 1, 0, "F0 43 10 4C 02 01 00 $X3 F7" # $X3が第3引数の16進数大文字に置き換わります
END_MACRO

# 呼び出し時にノート番号やSysExパラメータを引数として渡す
CALL_MACRO, MY_MELODY, 1, 0, 0, 60, 64, 127
```

### ループと条件分岐

`LOOP_START` 〜 `LOOP_END` はネスト（入れ子）可能です。

| コマンド            | パラメータ        | 説明                                     |
|:----------------|:-------------|:---------------------------------------|
| `LOOP_START`    | `count` (整数) | ★ ループを開始し、`count` 回繰り返します。             |
| `LOOP_END`      | (なし)         | ★ ループを終了します。                           |
| `LOOP_LAST`     | (なし)         | ★ この行以降はループの **最終回のみ** 実行されます（フィルイン用）。 |
| `LOOP_NOT_LAST` | (なし)         | ★ この行以降はループの **最終回以外** で実行されます。        |

**ループ分岐の例:**

```
LOOP_START, 4       # 4回ループ
  # --- 1〜3回目と4回目共通のパターン ---
  NOTE, 9, 9, 0, 36, 120, 100

  LOOP_NOT_LAST        # --- 最終回以外 (1〜3回目) ---
  NOTE, 9, 9, 480, 38, 100, 100 # 通常のスネア

  LOOP_LAST         # --- 最終回 (4回目) のみ ---
  NOTE, 9, 9, 480, 49, 127, 240 # フィルインのクラッシュシンバル

LOOP_END
```

### イベント（テンポ・拍子・調号・SysEx）

以下のコマンドは、コンパイラを通じて標準MIDIイベントとしてアセンブルされます。

| コマンド        | パラメータ                         | 説明                                                                                         |
|:------------|:------------------------------|:-------------------------------------------------------------------------------------------|
| `TEMPO`     | `trk`, `ST`, `bpm`            | テンポ（BPM）を設定します（小数の指定も可能）。                                                                  |
| `TIMESIG`   | `trk`, `ST`, `num`, `denom`   | 拍子を設定します。`num`: 分子, `denom`: 分母（※分母は2の累乗: 1, 2, 4, 8, 16 等である必要があります）。                     |
| `KEYSIG`    | `trk`, `ST`, `sf`, `mi`       | 調号を設定します。<br>- `sf`: シャープ(+)/フラット(-)の数 (-7〜+7)<br>- `mi`: 0(Major) / 1(Minor)              |
| `META_TEXT` | `trk`, `ST`, `type`, `"text"` | 汎用テキストイベントを記録します。<br>- `type`: 1(Text), 2(Copyright), 3(TrackName), 5(Lyric), 6(Marker) など |
| `SYSEX`     | `trk`, `ST`, `"hex data"`     | システムエクスクルーシブメッセージ。スペース区切りの16進数文字列で記述します（例: `"F0 7E 7F 09 01 F7"`）。                         |

## コマンドライン操作

### コマンドライン引数（オプション）

Ramidi は以下のコマンドライン引数に対応しています。

| オプション             | 引数                                         | 説明                                                                                                                                                                                                       |
|:------------------|:-------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--stage=<stage>` | `midi`, `raw`, `wav` (または `master`), `mp4` | 処理を終了するステージを指定します（デフォルト: `mp4`）。<br>- `midi`: SMF形式のMIDIファイル生成までで終了します。<br>- `raw`: FluidSynthによるRAW WAVレンダリングまでで終了します。<br>- `wav` (または `master`): マスタリング処理（WAV）までで終了します。<br>- `mp4`: MP4動画生成まですべて実行します。 |
| `--cover=<path>`  | 画像ファイルパス                                   | MP4生成時に背景として使用するジャケット画像ファイルのパスを指定します。<br>未指定時のデフォルト動作:<br>入力 `.ramidi` と同階層にある `cover.jpg` を優先して探索し、なければ `cover.png` を使用します。                                                                             |
| `--no-play`       | なし                                         | 処理完了後のOS標準プレイヤーによる自動再生を無効化します。CI/CD環境やバッチ処理などで便利です。                                                                                                                                                      |

#### コマンドライン引数の実行例

```bash
# MIDIファイルのみを高速に出力（オーディオレンダリングをスキップ）
ramidi song.ramidi --stage=midi

# マスタリング済みWAVまで出力し、再生は行わない
ramidi song.ramidi --stage=wav --no-play

# 独自のジャケット画像を指定してMP4動画を生成
ramidi song.ramidi --cover=/path/to/artwork.png
```

## MP4動画生成機能

### MP4動画の仕様

- **解像度**: 1280 x 720 (HD, 16:9)
- **フレームレート**: 30 fps
- **映像コーデック**: H.264 (`libx264`), ピクセルフォーマット `yuv420p`
- **音声コーデック**: AAC (`320kbps`, 44.1kHz)
- **波形表示**: LR独立の2チャンネル（マルチチャンネル）波形アニメーション（`Cyan` / `Magenta`）

### カバー画像の自動判定

1. **カバー画像がある場合**:
    - 入力ファイルと同階層の `cover.jpg` または `cover.png`（または `--cover` で指定された画像）を
      1280x720 に自動クロップ・リサイズして背景に配置します。
    - 背景画像の下部（下端から40px上）に、高さ240pxのLR分割波形アニメーションが美しく合成されます。
2. **カバー画像がない場合**:
    - 黒背景の中央にLR分割波形アニメーションが配置された動画が生成されます。カバー画像が用意されていない状態でも問題なく動画出力が可能です。
